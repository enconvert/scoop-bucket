# EnConvert Scoop Bucket

Scoop bucket for the [EnConvert CLI](https://github.com/enconvert/cli) on Windows.

```powershell
scoop bucket add enconvert https://github.com/enconvert/scoop-bucket
scoop install enconvert
```

The manifest in `bucket/` is generated automatically by the release pipeline in
[enconvert/cli](https://github.com/enconvert/cli); do not edit it by hand.
